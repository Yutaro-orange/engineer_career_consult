# プロダクト概要

エンジニア向けキャリア診断Webアプリケーション。10問の質問に回答することで、ユーザーの性格・適性を分析し、最適なキャリアパスを提案する。

## コア機能

- **キャリア診断**: 質問ベースの診断フローで性格タイプ・適性を分析
- **スキル分析**: GitHub APIと連携し、ユーザーのリポジトリからスキルセットを可視化
特に強みとなる技術スタックをユーザーに対して明確に偏差値などで数値化
- **診断後メニュー**: 診断結果に基づくチャット・スキル画面への導線
チャットではOpenAIを用いてキャリアアドバイザーとして提案
※OpenAIの応答のためのプロンプトについては管理画面で設定・編集が可能

## ターゲットユースケース

- エンジニアが自身のキャリア適性を知りたいとき
- GitHubプロフィールから技術スキルの傾向を客観的に把握したいとき
- キャリアの方向性について対話的なアドバイスを得たいとき
- エンジニアにとって最適な転職エージェントを知りたいとき

## 価値提案

質問回答による性格分析とGitHubデータによるスキル分析及びチャット履歴を組み合わせ、データに基づいたキャリアアドバイスを提供する。日本語UIで日本のエンジニア市場に特化。
